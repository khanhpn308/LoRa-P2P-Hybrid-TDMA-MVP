# RF/MAC network model — not yet implemented

Future model under [#125](https://github.com/khanhpn308/LoRa-P2P-Hybrid-TDMA-MVP/issues/125): Event-only static DATA/ACK exchanges (W500/G50), same-Event retry in the next valid own slot, durable pending after bounded retry exhaustion, and Maintenance Superframes targeting 300s authenticated 32B HMAC SYNC_BEACON plus per-Node HEALTH_REPLY / 23B Diagnostic. Cover single-radio half duplex, DATA/Maintenance/Join/Recovery guards across boundaries, drift/holdover, missing ACK/Health, reboot, queue overflow, durable dedup and airtime admission. Local alarm and remote logging latency are separate observations. Normal priority contention and P-10S-15 are superseded; approved successor contracts and measured timing profiles are prerequisites. Models must be calibrated with measured RF/HIL data before being called a validated digital twin.
