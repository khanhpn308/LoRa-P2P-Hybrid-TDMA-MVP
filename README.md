# LoRa P2P Hybrid TDMA — MVP

ESP32 + SX1276 LoRa P2P network with a local TDMA Master gateway, Go planning backend, Mosquitto and PostgreSQL.

The repository is being bootstrapped through a reviewable pull request. Architecture, radio timing, security, and regulatory parameters are **not yet verified**. No LoRaWAN/ChirpStack stack is part of this MVP.
