## 2. Plan Lifecycle Policy & Worked Demonstration (`H2-STA-04`, `H2-STA-06`)

### 2.1 Single Source of Truth per State Surface
- **Scope & backlog:** GitHub Issues (`--issue`, [`scope.py`](../../scripts/agent_harness/scope.py)). No duplicate Markdown backlog.
- **Execution plan & active unit:** External Host SQLite `Journal` + [`feature_state.py`](../../scripts/agent_harness/feature_state.py) enforcing `WIP=1`, CAS revision checks, and Host-sealed transitions (`host_verifier` only for `PASSING`).
- **Session handoff:** `feature_state.py session-start` / `checkpoint` / `session-close` with bounded redacted artifacts outside the candidate worktree.

### 2.2 Plan Lifecycle States & Worked Disposable Demonstration
Allowed transitions enforced by [`advanced_pack.py`](../../scripts/agent_harness/advanced_pack.py) (`transition_plan_lifecycle`):
`DRAFT -> ACTIVE -> COMPLETED -> ARCHIVED` (with `ACTIVE <-> BLOCKED` for missing prerequisites or scope/authority stops).

- **Worked example (disposable fixture verified in [`test_advanced_pack.py`](../../tests/agent_harness/test_advanced_pack.py)):**
  1. **Create (`DRAFT`):** `PLAN-P07-FIXTURE` starts in `DRAFT` linked to an Issue allowlist and frozen check plan.
  2. **Activate (`ACTIVE`):** Transition to `ACTIVE` (`WIP=1`).
  3. **Complete (`COMPLETED`):** Transition requires non-empty `evidence_ref` (e.g., Host `checks_summary.json` digest) and fails closed if missing.
  4. **Archive (`ARCHIVED`):** Transition requires both `evidence_ref` and explicit `approved_by` (Owner review); attempting `DRAFT -> ARCHIVED` or `COMPLETED -> ARCHIVED` without `approved_by` raises `ValueError`.

## 3. Six-Dimension Evaluator Rubric vs. Human Review Findings

The 6-dimension `0–2` evaluator rubric in [`audit.schema.json`](../../scripts/agent_harness/adapters/audit.schema.json) (`correctness`, `verification`, `scope_discipline`, `reliability`, `maintainability`, `handoff_readiness`) is **strictly separate** from domain grades in [QUALITY_SCORE.md](../QUALITY_SCORE.md).

- **Hard-gate invariant:** `hard_gate_passed: false` or any unresolved `P0/P1` / `STOP` finding blocks `ACCEPT` regardless of the `0–12` sum (`validate_rubric` in [`antigravity.py`](../../scripts/agent_harness/adapters/antigravity.py) and `calibrate_rubric` in [`pr_review.py`](../../scripts/agent_harness/pr_review.py)).
- **Comparison with recorded repository review findings:**
  - *P01 Baseline Audit (`F01–F05`, [HARNESS_BASELINE_REPORT.md §9](phase-01/HARNESS_BASELINE_REPORT.md#9-finalization--remediation--audit-delta-log)):* Caught C rule count mismatch (`106` vs `104`), RTM `evidence_hash` ambiguity, and `OWNER_WAIVED` CI reporting — directly corresponding to `correctness` and `verification` penalties (`<=1`) despite complete artifact delivery.
  - *P05/P06 PR Reviews (`4cf6d4a`, `c5de98d`):* Caught incomplete unit verification definitions (`trusted_definitions`) and nested JSON secret redaction / `.tmp` ownership boundaries — confirming `verification` and `reliability` must remain evidence-bound, not self-attested.
- **Calibration Status:** **`NOT_VERIFIED`**. Although `pr_review.py --calibrate-rubric` implements the 3–5 tuning-round + blind held-out check, no Owner-approved human-labeled calibration dataset has been executed yet (`OD-06` / `OD-09`, scheduled `P08/P10`).
