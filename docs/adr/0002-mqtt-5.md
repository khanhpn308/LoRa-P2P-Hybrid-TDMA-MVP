# ADR-0002: Chọn MQTT 5.0 cho Gateway ↔ Backend

- **Status:** Project Owner đã chọn; chờ review liên nhóm và merge.
- **Issue:** #14

## Context
ESP32 Gateway kết nối Mosquitto và Backend Go qua Wi-Fi/TLS. Schedule và command phải tránh thực thi khi đã quá hạn.

## Decision
- **MQTT 5.0** cho cả Gateway và Backend; MQTT 3.1.1 không thuộc contract v1. Dùng TLS, client identity và ACL.
- **QoS 1**; dedup bằng ID ứng dụng. MQTT PUBACK không chứng minh radio command/schedule đã thực thi.
- **Gateway:** Clean Start = 1, Session Expiry Interval = 0; subscribe lại sau reconnect; uplink offline buffer có giới hạn.
- **Backend:** Client ID cố định, Clean Start = 0, Session Expiry Interval > 0; giới hạn queue/persistence. Thời lượng cụ thể cần đo kiểm.
- **Downlink schedule/command:** Retain = false; PUBLISH bắt buộc có Message Expiry Interval không vượt thời gian còn lại đến `expires_at`. Gateway vẫn kiểm tra `expires_at`, ID, phiên bản và tính hợp lệ.
- Backend reconcile lịch sau reconnect; **Gateway thực thi TDMA cục bộ**, không dùng MQTT để kích hoạt từng slot.

## Consequences / Verification
Cần client MQTT 5.0 tương thích ESP-IDF/Go, kiểm thử TLS/ACL, QoS 1 duplicate, offline/reconnect và expiry. **NOT_VERIFIED** cho đến khi có integration evidence.

## Alternative
MQTT 3.1.1 đơn giản hơn nhưng thiếu Message Expiry và Session Expiry ở cấp protocol.

**Reviewers:** Gateway, Backend, Infrastructure/Security.
