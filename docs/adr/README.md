# Architecture Decision Records

Add ADRs in numbered Markdown files, e.g. `0001-go-modular-monolith.md`. Template: Context → Decision → Consequences → Alternatives → Status → Reviewers → linked GitHub Issue.

No assumption becomes a hard requirement merely because it appears in a proposal. Cross-component changes require review and versioning.
