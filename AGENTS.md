## Architecture
- ESP32-WROOM-32E + SX1276, C/FreeRTOS/ESP-IDF **v6.1** ([ADR-0003](docs/adr/0003-esp-idf-v6-1.md), `firmware/esp-idf-version.txt`). **Custom LoRa P2P MAC / Hybrid TDMA**, never LoRaWAN/OTAA/ADR/ChirpStack.
- Gateway owns local TDMA execution; Go Modular Monolith plans schedules via MQTT 5.0/TLS (Mosquitto), PostgreSQL; Next.js + TypeScript Web / Kotlin native Android through authenticated REST/WSS, never direct broker/DB. Backend must not time individual RF slots.
- Single SX1276 radio owner, serialized SPI, minimal nonblocking ISR/timer handling, bounded buffers/queues, explicit ownership/timeouts. Client authorization is enforced by Backend, not UI.
- Do not invent/modify unapproved RF/legal profile, PCB pins, binary frame, keys/replay, airtime/guard/drift, MQTT/API/DB semantics or latency targets; respect [open decisions](contracts/OPEN_DECISIONS.md). CRC is not authentication.
- **SX1276 reference routing (selective MVP V1):** When implementing SX1276 radio/PHY/driver firmware, consult only task-relevant files: entry point and scope ([README.md](docs/hardware/sx1276/README.md)), PHY configuration and channel plan ([SX1276_ACTIVE_PROFILE.md](docs/hardware/sx1276/SX1276_ACTIVE_PROFILE.md)), SPI/reset/TX/RX/IRQ/FIFO/timeout/recovery/Radio Owner ([SX1276_DRIVER_OPERATIONS.md](docs/hardware/sx1276/SX1276_DRIVER_OPERATIONS.md)), or register addresses/bitfields/masks/operations ([SX1276_REGISTER_REFERENCE.md](docs/hardware/sx1276/SX1276_REGISTER_REFERENCE.md)). Read only what the task requires; do not require all four files for every issue. Never load SX1276 references for Backend, Web, or unrelated tasks. Distinguish this lightweight task routing from blocked #118 Context Packs. Do not load PDF citations, historical audit, or non-MVP sources into Hot Context; do not invent or assume `TBD` values (preamble, TX power/PA path, gain/AGC, host RX guards, TDMA timings) as approved. Existing source authority priority remains unchanged (approved architecture/ADRs and contracts > manufacturer datasheets > exact SDK version); conflicts require `STOP_AND_REPORT`.

Deterministic Host independently unions minimal safety, path, dependency and operation rules from the Issue allowlist and actual diff; validates tracked compact indexes and source/blob/row hashes; injects only bounded selected rows before Worker edits. Never inject either whole standard or all IDs. Docs-only work does not load unrelated standards; firmware-only/backend-only work does not load the other component without an actual dependency.
- Recompute after every diff/scope change and before fresh Auditor. Newly required IDs need renewed injection and focused repair/review; outside-allowlist changes stop. Auditor receives independently verified frozen selected rows, full diff and per-ID evidence. Missing/malformed/unknown/duplicate/ambiguous IDs, incomplete injection, stale sources or receipts, unresolved STOP findings and unreviewed exceptions block automatic acceptance. Worker declarations alone are not compliance evidence.
- Consult only selected rules and their affected blocked decisions/evidence; inspect `firmware/esp-idf-version.txt`, `.go-version` and `backend-go/go.mod` when relevant. Native instructions alone do not instrument every Codex/AGY UI entrypoint; distinguish tested Host checks, actual supervised runs and technical human approval.

## Native workflow and verification
- **Mandatory G0 context:** A trusted Host must run `python3 scripts/agent_harness/agent_context.py --repo <candidate>`, validate the exact tracked `AGENTS.md` SHA/bytes, and inject its complete `agent_input` into the Worker context **before any edit**; give the Auditor the same version. Missing/dirty/symlinked/drifted file or unavailable Host gate => `BLOCKED`. Log the source SHA/AGENTS SHA256 as a receipt. Reading verification is Host input evidence, not proof of model comprehension. A plain interactive CLI without a supervising Host cannot claim hard enforcement.
- Default: [Native Fast Lane](docs/development/harness-fast-lane.md): `Chạy Issue #N` → isolated Issue branch/worktree → Codex or `agy` Worker → applicable [quality gates](docs/development/harness-quality-gates.md) and actual Host receipts → fresh read-only Auditor → Draft PR → **human review/merge**. `Nghiệm thu PR #N` is read-only unless fixes are authorized. No direct coding on `main` or destructive Git operations.
- From a trusted checkout, check candidate/diff/evidence fingerprints **before and after** audit; missing checks, unresolved P0/P1 findings or human security review block `READY_TO_MERGE`. Signed MCP is a separate optional mode requiring its own authorization. [Task Start Protocol](docs/development/AI_TASK_START_PROTOCOL.md) remains DRAFT; legacy P0/P1 simulated pilots do not establish Native Fast Lane E2E PASS.
- Human technical review required for RF/hardware, SPI/ISR/timer, security/crypto, pins and versioned contracts. Never auto-merge, auto-flash, transmit RF, expose credentials, bypass permissions or treat Full Access as auditor isolation.
- Report exact Issue/base/head SHA, changed vs allowed paths, consulted Rule IDs and approval status, toolchain, tests/receipts/NOT_RUN, findings, reviewer requirements and Draft PR URL. Build/CI, simulation, audit, security, HIL, RF and G0–G6 are **independent evidence**; absent proof is `NOT_VERIFIED`. GitHub Actions `OWNER_WAIVED` ≠ CI PASS and does not waive local checks.
